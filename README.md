# Gadget Link API

ガジェット特化型リンク集サービス「Gadget Link」のバックエンド（API）サーバーです。

## プロジェクト概要
ガジェット情報の管理、ユーザープロフィール管理、および認証機能を提供します。
Go 言語とドメイン駆動設計（DDD）を採用しています。

## ディレクトリ構成案 (DDD)

本プロジェクトは、以下のレイヤードアーキテクチャ/DDDに基づいた構成で開発を進めます。

```text
├── cmd/
│   └── api/
│       └── main.go           # エントリポイント。依存解決（DI）とサーバー起動を行う
├── internal/                 # アプリのコアロジックを格納（外部公開されない）
│   ├── domain/               # 【ドメイン層】ビジネスルールとモデル定義
│   │   ├── model/            # User, Gadget などのエンティティや値オブジェクト
│   │   ├── repository/       # リポジトリ（保存・取得）のインターフェース
│   │   └── service/          # 認証検証やトークン生成などのドメインサービス定義
│   ├── application/          # 【アプリケーション層】ユースケース（ログイン、取得など）
│   ├── handler/              # 【インターフェース層】HTTPハンドラ。リクエストの解析とレスポンス
│   └── infrastructure/       # 【インフラ層】技術的詳細実装
│       ├── auth/             # JWT生成、Google IDトークン検証の具体実装
│       ├── persistence/      # リポジトリの具体的実装（SQLiteなど）
│       └── sqlite/           # DB接続初期化やマイグレーション設定
├── go.mod                    # 依存関係管理
└── go.sum
```

## 技術スタック
- **言語:** Go (Golang)
- **ルーター:** chi (v5)
- **データベース:** SQLite
- **アーキテクチャ:** Domain-Driven Design (DDD)
